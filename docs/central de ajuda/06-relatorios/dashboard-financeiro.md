# Dashboard financeiro

## Objetivo

Ensinar a ler o painel executivo com saldo, resultado, saidas previstas e alertas.

## Quando usar

Quando a direcao ou o gestor precisa de uma leitura rapida da situacao financeira.

## Passo a passo

1. Abra o dashboard financeiro.
2. Leia os indicadores principais.
3. Analise o grafico de evolucao.
4. Revise contas a vencer e top despesas.
5. Use os detalhes abertos para investigar um numero especifico.

## Pontos de atencao

- o dashboard resume, nao substitui a operacao;
- filtros mudam completamente a leitura;
- os detalhes servem para investigar a causa.

## Erro comum

Tomar o dashboard como fechamento contabil definitivo.

## Resultado esperado

O usuario entende rapidamente a posicao de caixa e pressao do periodo.
